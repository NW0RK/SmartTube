# NikoTube 32.70

Stable Android package: org.smarttube.stable. Requires Android 8.0 or newer.

- YouTube-first dark design with NikoTube branding, clearer video cards, and a player-first watch page.
- Home, History, and You navigation. The bottom bar hides while scrolling down and returns when scrolling up or changing sections. Subscriptions remains available in the section chips.
- Button feedback fills the button shape, including Share and other watch actions.
- Vertical search suggestions, consistent menus, and shared design tokens.
- DESIGN.md and repository guidance document the visual system for future changes.

Signed with the existing NikoTube stable key. Existing installations using that key can update in place.

The final build was made without further tests or device checks at the user's request. Earlier intermediate checks do not establish verification of the final navigation and feedback changes. Existing playback test fixtures still require migration to service-owned playback.
