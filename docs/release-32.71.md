# NikoTube 32.71

Stable Android package: org.smarttube.stable. Requires Android 8.0 or newer.

- Removed the browse top bar and moved Search to the bottom navigation.
- OLED black bottom navigation with centered icons and no text labels.
- Smooth ease-in/ease-out animation when scrolling the navigation away and back.
- Returning from a comment thread restores the previous comment list position.

Signed with the existing NikoTube stable key for in-place updates. The beta installation is unchanged.

Built without tests, lint, or device checks at the user's request. These UI behaviors remain unverified on a device.
