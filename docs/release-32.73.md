# NikoTube 32.73

Stable Android package: `org.smarttube.stable`. Requires Android 8.0 or newer.

- Like, dislike, and subscribe requests now show service errors and restore the previous button state when the service rejects an action.

The stable signing identity is retained. Beta installations are unchanged.

Tests and device checks were not run at the user's request. Runtime behavior remains unverified.
